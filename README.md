🌿 Greenden – Responsive Website using HTML & Tailwind CSS

📌 Overview

Greenden is a responsive, multi-page website built using HTML and Tailwind CSS. The project focuses on creating a clean and modern user interface while helping students understand real-world website layout practices. It emphasizes the use of Tailwind’s utility-first approach to build flexible, attractive, and maintainable designs.

This project is ideal for beginners who want hands-on experience with responsive web design and modern CSS frameworks.

⸻

🧩 Website Structure

The Greenden website consists of a well-organized navigation bar and three main pages:

🏠 Home Page
	•	Welcomes users with an eye-catching layout
	•	Provides a brief introduction to the Greenden brand
	•	Designed with proper spacing, typography, and alignment

🪴 Products Page
	•	Displays green-themed or plant-related products
	•	Uses grid/card layouts for a clean and organized look
	•	Fully responsive across different screen sizes

📞 Contact Page
	•	Contains neatly styled contact information
	•	Includes a structured section for user interaction
	•	Maintains a professional and minimal design

⸻

📱 Responsive Design
	•	Fully responsive layout that adapts smoothly from mobile devices to desktops
	•	Implemented using Tailwind CSS responsive utilities:
	•	sm: for small screens
	•	md: for medium screens
	•	lg: for large screens
	•	Ensures consistent design, spacing, and readability across all devices

⸻

🎯 Learning Objectives

By working on this project, you will learn to:
	•	Build a multi-page responsive website using Tailwind CSS
	•	Work efficiently with Flexbox, Grid, spacing, and typography utilities
	•	Write clean, reusable, and maintainable HTML with Tailwind classes
	•	Design aesthetic, accessible, and user-friendly interfaces
	•	Gain confidence in applying Tailwind CSS to real-world projects

⸻

✅ Outcome

After completing the Greenden project, you will have:
	•	A fully responsive website built using HTML & Tailwind CSS
	•	Practical experience in modern UI design principles
	•	A polished web project suitable for your portfolio or resume
	•	Strong foundational skills for building scalable front-end projects
